Spotify + Claude on macOS

Control Spotify with natural language — ask Claude to play music, build playlists, and more.

Before you start

  • 🎧 Spotify Premium account
  • 🍎 macOS
  • 🌐 Internet connection
  • ⏱ About 20–30 minutes
Setup
✓
Step 1
Open Terminal

Terminal is where you type commands. It looks technical, but you're just copy-pasting — nothing to worry about.

  1. Press ⌘ Space to open Spotlight search
  2. Type Terminal
  3. Press Enter

A window with a dark or white background and a blinking cursor will open. Keep it open throughout this guide.

✓
Step 2
Download the project

Copy and paste the following three commands into Terminal, one at a time. Press Enter after each one.

Terminal 
cd ~/Desktop
git clone https://github.com/jerzyszajner/spotify-mcp.git
cd spotify-mcp
Note: If a pop-up asks you to install developer tools, click Install and wait for it to finish. Then paste the commands again.

When done, a folder called spotify-mcp will appear on your Desktop.

✓
Step 3
Install Node.js 24

Node.js is a runtime that the server needs to run. You need version 24 or newer.

  1. Open your browser and go to nodejs.org/en/download
  2. Click macOS Installer (.pkg) — make sure the version says 24.x or higher
  3. Open the downloaded file and follow the installer steps (Continue → Continue → Install)
  4. When it's done, go back to Terminal and run this to verify:
Terminal — verify 
node --version
It should print something like v24.15.0. Any number starting with 24 or higher is fine.
✓
Step 4
Build the server

Make sure you're still inside the spotify-mcp folder in Terminal, then run:

Terminal 
npm install
npm run build

You'll see a lot of text scroll by — that's completely normal. Wait until the $ prompt comes back.

Success: no lines containing the word ERROR in red, and a new build/ folder appears inside spotify-mcp.
Spotify Developer Setup
✓
Step 5
Create a Spotify Developer App

You need to create a free "developer app" on Spotify's website to get an API key. It takes about 2 minutes.

  1. Go to developer.spotify.com/dashboard and log in with your Spotify account
  2. Click Create app
  3. Enter any name, e.g. My Claude Controller, and a short description
  4. In the Redirect URIs field, type exactly:
Redirect URI — copy this exactly 
http://127.0.0.1:8888/callback
  1. Click Add next to the URI field
  2. Check the box agreeing to Spotify's terms, then click Save
  3. You'll see your app's dashboard — find the Client ID (a long string of letters and numbers) and copy it to your Notes app — you'll need it in the next step
Important: The Client ID is not a password, but treat it as one — don't share it publicly.
✓
Step 6
Add your Client ID to the config file

Run this in Terminal to create the config file and open it:

Terminal 
cp spotify-config.example.json spotify-config.json
open spotify-config.json

The file opens in TextEdit. It looks like this:

spotify-config.json
{
  "clientId": "your-client-id",
  "redirectUri": "http://127.0.0.1:8888/callback"
}
  1. Replace only the text your-client-id (between the quotes) with the Client ID from Step 5 — keep the quotation marks before and after
  2. Leave redirectUri exactly as it is
  3. Save with ⌘ S and close TextEdit
If TextEdit saved the file as Rich Text, switch to Format → Make Plain Text (⌘⇧T) before editing, then save again.
✓
Step 7
Authenticate with Spotify

Run this in Terminal:

Terminal 
npm run auth
  1. Your browser will open a Spotify authorization page automatically
  2. Log in to Spotify if asked, then click Agree or Authorize
  3. The browser will show a blank or "localhost" page — that's normal, it worked
  4. Back in Terminal you'll see: Authentication completed successfully!
Browser didn't open? Terminal will print a URL starting with https://accounts.spotify.com/ — copy it and paste it manually into Safari.
Claude Desktop
✓
Step 8
Install Claude Desktop

Claude Desktop is the app you'll talk to — it will control Spotify on your behalf.

  1. Go to claude.ai/download
  2. Click Download for Mac — this always downloads the latest version
  3. Open the downloaded .dmg file
  4. Drag the Claude icon into the Applications folder
  5. Open Claude from Applications and sign in (or create a free Anthropic account)
Required: Turn off AI training data sharing — Spotify's terms require it.
Go to Claude menu → Settings → Privacy and disable the data sharing / model training option.
(These steps were written for Claude Desktop as of April 2026 — if the UI looks slightly different, the option will still be in Settings → Privacy.)
✓
Step 9
Find the path to the server

Claude needs to know exactly where the server file is. Run this in Terminal:

Terminal 
cd ~/Desktop/spotify-mcp
pwd

Terminal will print something like:

Example output
/Users/yourname/Desktop/spotify-mcp

Take that path and add /build/index.js to the end. For example:

Your full server path will look like this
/Users/yourname/Desktop/spotify-mcp/build/index.js

Write this down or keep it visible — you'll need it in the next step.

✓
Step 10
Connect Claude Desktop to Spotify
  1. Open Claude Desktop
  2. In the menu bar at the top, click Claude → Settings
  3. Click Developer, then Edit Config
  4. A file called claude_desktop_config.json opens in TextEdit
  5. Look at the file — if it's empty or contains only {}, select all (⌘ A) and replace the entire content with the block below.
    If the file already has other MCP servers listed, don't replace everything — instead add only the "spotify": { … } entry inside the existing "mcpServers" object.
claude_desktop_config.json 
{
  "mcpServers": {
    "spotify": {
      "command": "node",
      "args": ["/Users/yourname/Desktop/spotify-mcp/build/index.js"]
    }
  }
}
Replace /Users/yourname/Desktop/spotify-mcp/build/index.js with the path you got in Step 9. The rest stays exactly as shown.
  1. Save with ⌘ S and close TextEdit
  2. Quit Claude Desktop completely: ⌘ Q
  3. Reopen Claude from Applications
✓
Step 11
Test it!
  1. Open Spotify on your Mac, iPhone, or any device and start playing something (or just have it open)
  2. Open Claude Desktop and start a new conversation
  3. Type: What song is playing on Spotify right now?
Claude should respond with the current track name and artist. If it does — you're all set! 🎉

Try asking things like:

  • "Play something by The Beatles"
  • "Create a playlist called Chill Evenings and add 10 relaxing tracks"
  • "What are my top tracks this month?"
Troubleshooting
🔧
Something not working?
ProblemFix
node: command not found Close Terminal and open it again after installing Node.js
npm run auth — browser doesn't open Copy the URL printed in Terminal (starts with https://accounts.spotify.com/) and paste it into Safari
Claude doesn't know about Spotify Check the path in claude_desktop_config.json has no typos and exactly matches what pwd printed. Make sure you fully quit Claude (⌘ Q) and relaunched it.
ENOENT spotify-config.json Go back to Step 6 and run cp spotify-config.example.json spotify-config.json again
Error about "npm run build" failing Make sure you're inside the spotify-mcp folder: run cd ~/Desktop/spotify-mcp first, then retry
